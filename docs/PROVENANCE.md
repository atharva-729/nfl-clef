# Provenance

What came from `clef-video-probe`, and what has changed since.

Source: `../clef-video-probe` at commit `9daec107736e0e2dc93fb74eb5d62eae998def19`
("Phases 3-8: Clef runs, evaluation, events, replay, comparisons, story page"), clean working tree
for these files. Copied on 2026-10-12.

## Copied files

Every file below is currently **byte-identical** to the source. The changes the README calls for
are made in the phase that needs them and recorded here when they happen.

| File | Status now | Change still to make | Phase |
|---|---|---|---|
| `src/clef_client.py` | verbatim | none expected | n/a |
| `docs/api_notes.md` | verbatim | append anything new learned (61-option questions, PNG frames) | 1 |
| `src/run_clef.py` | verbatim | frames are `f_NNNN.png` with times in `data/frames_index.csv` (it expects `f_*_t<sec>.jpg`); default budget 5.00; add `--with-captions` | 4, 8 |
| `src/evaluate.py` | verbatim | make it schema-driven (drop the rocket `GROUPS` and the `make_label_sheet.NUMERIC` import, read `data/labels/labels.csv` as written by `make_labels.py`); add exact-match and off-by-1 for scores, per-team metrics, split by `main_view` | 5 |
| `src/detect_events.py` | verbatim | replace the rocket `TRANSITIONS` with the football rules; hit window `[-5 s, +20 s]`; read the new `events_truth.csv` columns | 6 |
| `src/build_replay.py` | verbatim | YouTube IFrame player instead of a local mp4; football panel | 7 |
| `replay/index.html` | verbatim (generated by `build_replay.py`) | regenerated in Phase 7 | 7 |
| `data/labels/label_helper.html` | verbatim (still lists the rocket frame names) | football frames, "draft vs reviewed" view, CSV export | 3 |

`src/evaluate.py` and `src/build_replay.py` import `make_label_sheet`, which was not copied, so
they do not run until their phase's changes are made.

## Changes made since the copy

| File | Phase | What changed |
|---|---|---|
| `src/clef_client.py` | 1 | `ask(..., crop=box)` sends that region of the frame as a second, full-resolution image and adds a sentence about it to the state (`crop_jpeg`, `CROP_NOTE`). Nothing else. |
| `src/run_clef.py` | 4 | Frames are `f_NNNN.png`; times come from `data/frames_index.csv`; the scorebug crop box from `config.yaml` is sent and is part of the cache key; default budget 5.00; token fallback 7,000. `--with-captions` still to add (Phase 8). |
| `src/evaluate.py` | 5 | Football question groups; reads `data/labels/labels.csv` (labels are already answer options, so the raw-number bucketing and the `make_label_sheet` import are gone); soft-label questions starred and kept out of the headline; exact / within-1 for scores; celebration by team; scorebug accuracy by kind of shot; cost per broadcast hour. The scoring maths is unchanged. |
| `src/detect_events.py` | 6 | Smoothing (`stable_changes`) unchanged. Rocket transitions replaced by the football rules; conversions are tied to the next 1- or 2-point rise after a touchdown, not to a 4-frame window; hits use the `[-5 s, +20 s]` window and match repeated events one to one; reads the new `events_truth.csv`. |
| `src/build_replay.py`, `replay/index.html` | 7 | Rewritten around a frame flipbook (embedding is disabled, so no YouTube player and no local mp4): a virtual video clock steps through 1280x720 copies of the frames in `replay/frames/`, with an "open on YouTube at this moment" link. Football panel (scorebug as Clef read it, events, highlight strip, sponsor exposure). The page layout, styling and ground-truth toggle are carried over. |

The table under "Copied files" describes the state at the time of the copy.
